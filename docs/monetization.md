# Монетизация Apify акторов

## Модель доходов

- Разработчик получает **80%** от выручки (Apify берёт 20%)
- Формула: `(0.8 × revenue) - platform_usage_costs = прибыль`
- Или: если передаёшь platform costs пользователю → `0.8 × revenue` чистыми
- PPE — единственная активная модель с апреля 2026 (rental умер, мигрирует до октября 2026)

## Creator Plan ($1/месяц)

- $500 кредитов единоразово на первые 6 месяцев
- Кредиты для: разработки, дебаггинга (каждый тестовый запуск стоит), субсидирования первых юзеров
- После 6 месяцев — $1/месяц без бонуса
- Кредиты не переносятся на следующий цикл
- Получить один раз (бонус не обновляется)

## Compute costs (твои расходы при тестировании)

- $0.004 / GB-RAM-hour (очень дёшево)
- Skool актор, 100 постов, ~3 минуты, 256MB RAM = **$0.0005 за ран**
- 1000 тестовых запусков ≈ $0.50 — практически бесплатно

## Расчёт для Skool AI Lead Hunter

```
Цена пользователю:   $0.005 / signal (PPE)
LLM cost (OpenRouter): ~$0.001 / post classified (Gemini Flash)
Compute:             ~$0.0003 / run
Proxy:               $0 (Skool работает с cookies, прокси не нужны)

На 1000 signals:
  Выручка:           $5.00
  LLM (5000 posts):  $5.00   (если классифицировать 5 постов на 1 signal)
  Compute:           $0.15
  Итого costs:       $5.15
  Прибыль:           0.8 × $5 - $5.15 = -$1.15  ← убыток при плохом соотношении

Оптимизация: поднять цену или снизить LLM cost
  Цена $0.01/signal → 0.8 × $10 - $5.15 = $2.85 профит
  Gemini Flash ≈ $0.0001/1k tokens → на 1 post ≈ $0.000075 → negligible
```

Реальный сценарий (правильный): классифицировать ДЁШЕВО (Gemini Flash), заряжать только за SIGNAL.

## Вывод по ценообразованию

Оптимальная цена: **$5-10 / 1000 signals** (не posts, а signals).
Пользователь платит за лиды, не за данные — это другая ценовая категория.
Конкурент silentflow берёт $3.50/1000 posts → мы можем взять $10/1000 signals и это дешевле в пересчёте на лид.
